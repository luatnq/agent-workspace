Token economics

Bốn công thức và một bảng hệ số để ước lượng cost/latency của một tính năng LLM trong 2 phút. Đi kèm Bài 1.

Mental model

  • Stateless. f(context) → tokens. Mỗi lượt gửi lại toàn bộ lịch sử. "Memory" là việc của app.
  • Context window = working memory. Trọng số = "vague recollection". Muốn model biết chắc → đưa vào context.
  • Mọi thứ đều tính vào context: system prompt, messages, tool definitions, tool results, ảnh/PDF, thinking, output. Cache không đổi điều này.
  • Context rot: càng nhiều token, accuracy/recall càng giảm. 1M là trần, không phải mục tiêu.

Công thức

cost_lượt      = in × p_in + out × p_out
in_lượt_k      = system + Σ(lịch sử k−1 lượt) + user_k
in_hội_thoại   = n × system + (u + o) × n(n−1)/2 + n × u     # n lượt, u/o = user/output tb
latency_lượt   ≈ TTFT(∝ input, nhẹ hơn khi cache hit) + out / tốc_độ_sinh

Ba hệ quả: (1) trong hội thoại dài, input thường là phần cost lớn nhất dù giá/token rẻ hơn output 5 lần; (2) output quyết định latency; (3) thinking = output về cả cost lẫn latency.

Non-determinism

Temperature 0 không đảm bảo output giống hệt giữa các lần gọi (glossary chính thức). Test LLM bằng tiêu chí (eval), không bằng string equality.
