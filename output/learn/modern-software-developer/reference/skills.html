Skill

Tài liệu onboarding nạp lười: thư mục gồm SKILL.md, tài liệu tham chiếu và script. Model quyết định nạp, và chỉ dựa vào description.

Ba tầng nạp

TầngNạp khiGiới hạn
1. name + descriptionLuôn, ở mọi phiên~100 token/skill; cắt ở 1.536 ký tự (description + when_to_use); cả listing ≤ 1% context window, vượt thì bỏ description của skill ít dùng nhất
2. Thân SKILL.mdModel (hoặc người) gọi Skill< 500 dòng, < 5.000 token; nằm lại trong hội thoại, không đọc lại; sau compaction giữ 5.000 token đầu/skill, tổng 25.000
3. references/, scripts/, assets/Khi chỉ dẫn bảo cầnTham chiếu sâu 1 tầng; file > 100 dòng có mục lục; script chỉ tốn output

Nguồn: Claude Code — Skills; Agent Skills spec; Best practices. Kiểm tra: /context (hàng Skills), /doctor, /skill-doctor, claude plugin validate .claude/skills.

Checklist audit

  1. Description có cả làm gì và khi nào, nêu cả cách nói tắt ("kể cả khi tôi chỉ nói…"), và nói khi nào không dùng.
  2. Thân < 500 dòng; chỉ dẫn quan trọng nhất nằm ở đầu (sống sót qua compaction).
  3. Tham chiếu sâu một tầng; tên file tự mô tả.
  4. Phần mong manh đã thành script, và chỉ dẫn nói rõ "chạy" hay "đọc".
  5. Đã đo trigger: có câu dương, có câu âm.

Trigger eval an toàn

claude -p "$q" --tools "Skill" --strict-mcp-config --max-turns 1 \
  --output-format stream-json --verbose |
jq -r 'select(.subtype=="init") | "tools=" + (.tools|join(","))
     , (select(.type=="assistant") | .message.content[]? | select(.type=="tool_use") | "skill=" + .input.skill)'

--allowedTools chỉ duyệt trước, không gỡ tool (ở defaultMode: auto, Write vẫn chạy). --tools gỡ built-in nhưng để lại MCP. Luôn kiểm tra tools trong event init.
