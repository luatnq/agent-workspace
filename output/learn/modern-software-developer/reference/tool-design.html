Thiết kế tool cho agent

Tool là BFF cho model: viết cho người mới vào, chỉ biết tên tool, description, schema và output. Năm đòn bẩy là giả thuyết; eval mới là phán quyết.

Mẫu unit test (Python SDK 2.x, đã chạy với 2.3.0)

@pytest.fixture
def anyio_backend():
    return "asyncio"

@pytest.fixture
async def client(learn_dir):
    async with Client(build_server(learn_dir), raise_exceptions=True) as c:
        yield c

@pytest.mark.anyio
async def test_loi_co_goi_y(client):
    r = await client.call_tool("learn_get_progress", {"topic_slug": "x"})
    assert r.is_error and "modern-software-developer" in r.content[0].text

Server phải dựng qua factory (build_server(dir)), không đọc sys.argv ở cấp module. raise_exceptions=True chỉ dùng trong test. Nguồn: SDK v2 — Testing.

Đếm trong trace stream-json

# số lần gọi tool MCP
jq -r 'select(.type=="assistant") | .message.content[]? | select(.type=="tool_use") | .name' run.jsonl | grep -c mcp__
# số lỗi tool
jq -r 'select(.type=="user") | .message.content[]? | select(.type=="tool_result" and .is_error==true) | "E"' run.jsonl | wc -l
