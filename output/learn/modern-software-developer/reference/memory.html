Agent Memory

Khung lưu trữ trạng thái dài hạn cho AI Agent: vượt qua giới hạn phi trạng thái của LLM và ngân sách hữu hạn của context window.

Bốn ngăn nhớ theo khung CoALA

Ngăn nhớBản chấtĐặc điểmTương đương Backend
Working Memory Context window hiện tại Ngắn hạn, tốc độ cao, mất khi hết phiên hoặc sau compaction RAM / CPU Cache / ThreadLocal
Episodic Memory Nhật ký chuỗi sự kiện, hành vi trong quá khứ Tuần tự theo thời gian, append-only, lưu vết lỗi & quyết định cũ WAL / Audit Trail / Event Log
Semantic Memory Tri thức, sự thật, quy tắc trừu tượng Độc lập thời gian, được đúc kết từ nhiều trải nghiệm Normalized Relational DB (PostgreSQL)
Procedural Memory Kỹ năng, công cụ, quy trình hành động Logic thực thi tất định (Skills, MCP tools, scripts) Application Code / Stored Procedures

Nguồn: Sumers et al., "Cognitive Architectures for Language Agents" (CoALA), TMLR 2024.

Vòng đời 4 bước của ký ức

  1. Capture (Ghi nhận):
    • Explicit (Chủ động): Người dùng gõ lệnh (/remember). Chính xác 100%, không rác.
    • Implicit (Tự động): Model nền quét transcript tự trích xuất fact. Tiện lợi nhưng dễ lẫn rác và thông tin tạm bợ.
  2. Retrieve (Truy xuất):
    • Exact Index Pointer: Danh mục 1 dòng (MEMORY.md). Rẻ, chính xác, model tự đọc theo suy luận.
    • Vector Search (RAG): Cosine similarity qua embeddings. Mạnh khi ngữ nghĩa mơ hồ, nhưng mù mốc thời gian và làm nhòe từ khóa kỹ thuật.
    • Grep / Agentic Search: Harness hoặc model chủ động tìm kiếm file khi có nghi vấn.
  3. Consolidate (Đúc kết / Reflection):
    • Biến chuỗi trải nghiệm rời rạc (Episodic) thành quy tắc tổng quát (Semantic).
    • Loại bỏ chi tiết vụn vặt, gộp các sự cố trùng lặp thành một bài học duy nhất.
  4. Forget & Evict (Vô hiệu hóa & Quên):
    • Xóa hoặc cập nhật các mẩu nhớ đã hết hạn hoặc mâu thuẫn để chống "dirty read" trong context.
    • Quy tắc Phil Karlton: Cache Invalidation là một trong hai việc khó nhất trong Computer Science.

Quy tắc thiết kế memory sạch

  • Ngày tháng luôn tuyệt đối: Viết 2026-10-24, tuyệt đối không viết "hôm nay", "hôm qua", "tuần tới".
  • Phân định rõ ranh giới với AGENTS.md:
    • Sự thật bất biến, quy ước bắt buộc cho cả team → đặt ở AGENTS.md / CLAUDE.md.
    • Sở thích cá nhân, mục tiêu tạm thời, ghi chú thay đổi theo thời gian → đặt ở memory/.
  • Chiến lược Update > Insert: Khi có thông tin mới, luôn kiểm tra xem đã có ghi chú cũ liên quan chưa. Nếu có, cập nhật ghi đè (UPDATE) thay vì tạo file mới để tránh xung đột ngữ cảnh.
  • Dọn dẹp định kỳ (Eviction): Thông tin đã hoàn thành hoặc không còn giá trị nên chuyển vào memory/archive/ hoặc xóa hẳn.
