Claude Code: CLAUDE.md hoạt động thế nào

  • Là context, không phải cấu hình bắt buộc. Muốn chặn chắc chắn → PreToolUse hook.
  • Mọi file được nối theo thứ tự rộng → hẹp (global → project → thư mục con); không file nào đè file nào.
  • Hai luật mâu thuẫn → Claude có thể chọn bừa. Giữ các file nhất quán là việc của người viết.
  • Mỗi file nên dưới 200 dòng; dài hơn thì tuân thủ kém đi. Dùng .claude/rules/ theo path để chỉ nạp khi cần.
  • Luật cụ thể thắng luật chung chung: "Use 2-space indentation" tốt hơn "format code nicely".

ReAct = nghĩ → làm → quan sát → lặp. Quan sát thật chặn lỗi dây chuyền của suy luận thuần (Yao et al., ICLR 2023).

Checklist viết một luật trong CLAUDE.md

  1. Bắt đầu từ một lỗi thật đã xảy ra.
  2. Viết cụ thể, kiểm tra được (lệnh chính xác, đường dẫn chính xác).
  3. Hậu quả khó đảo ngược? → chuyển thành hook.
  4. Có mâu thuẫn với file global / file khác không?
