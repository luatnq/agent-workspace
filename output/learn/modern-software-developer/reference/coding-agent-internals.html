Coding agent internals

Agent = model + harness. Model chỉ sinh text. Harness làm mọi việc còn lại: cung cấp tool, thực thi, quản lý context, kiểm soát quyền.

Vòng lặp

while (user gõ input):
    conversation += user_msg
    while (true):                       # vòng trong
        resp = LLM(system + tools + conversation)
        calls = parse_tool_calls(resp)
        if calls rỗng: in resp; break
        for call in calls:
            result = harness.execute(call)   # model KHÔNG chạm file
            conversation += tool_result(result)

Ba pha theo Claude Code: gather context → take action → verify results, lặp lại và hòa vào nhau (nguồn).

Checklist: harness tối thiểu thiếu gì

  • Giới hạn số lượt, budget, nút ngắt.
  • Lỗi parse và tool lạ phải trả về cho model, không nuốt im lặng, không crash.
  • Message lỗi của tool phải chỉ cách sửa.
  • Có tool verify (bash); có quyền và sandbox cho thao tác ghi.
  • Compaction khi context dài.
