Instruction Files

Quy ước repo dành cho coding agent: mô hình Single Source of Truth, bảo vệ Prompt Caching, và chắt lọc quy ước thực sự tạo ra tác động.

Mô hình Single Source of Truth

  • AGENTS.md (Root repository): Hợp đồng chung cho toàn bộ dự án và mọi coding agent (Claude Code, Antigravity, Cursor, Codex). Chứa lệnh build/test, non-standard conventions và ranh giới kiến trúc.
  • Harness Adapters (CLAUDE.md, GEMINI.md, .cursorrules): File mỏng, chỉ import @AGENTS.md và chứa cấu hình điều phối agent / tool mapping đặc thù của harness đó. Không duplicate quy ước chung.

Nên đưa gì vào và tránh đưa gì vào

Dựa trên kết quả định lượng từ nghiên cứu thực nghiệm "Evaluating AGENTS.md" (Gloaguen et al., 2026 trên SWE-bench):

Nên đưa vào (Tăng độ chính xác)Tránh đưa vào (Lãng phí >20% token, làm loãng context)
Lệnh build & test chính xác: Giúp agent chạy kiểm tra ngay mà không cần mò mẫm thử sai. Mô tả tổng quan kiến trúc repo: Agent có thể tự khám phá cấu trúc file qua ls, find, grep khi cần.
Non-standard conventions: Các quy ước khác thường mà model không thể tự đoán từ pre-training (custom wrapper, quy tắc entity, thư viện cấm dùng). Kiến thức lập trình phổ thông: Dạy model "REST API là gì" hoặc các convention Java chuẩn đã có sẵn trong sách giáo khoa.
Ranh giới cấm vi phạm: File migration database đã merge, schema protobuf dùng chung, branch production. Tài liệu README dài dòng: Nhồi nhét hàng nghìn dòng tài liệu nghiệp vụ biến context thành bãi rác.

Quy tắc bảo vệ Prompt Caching (Prefix Cache)

  • Giữ file tĩnh tuyệt đối: AGENTS.md nằm ở vị trí đầu tiên của prompt (prefix). Bất kỳ ký tự biến động nào (như ngày giờ, branch name, kết quả lệnh động) sẽ làm vỡ toàn bộ cache breakpoint ở các lượt sau, mất sạch 90% ưu đãi chi phí.
  • Không sửa file theo việc ngắn hạn: Các ghi chú tạm thời theo ngày/giờ phải đưa vào prompt của user hoặc memory/.
  • Giữ độ dài dưới 150 dòng: File càng ngắn, model càng tập trung cao độ và không bị rơi vào bẫy "Lost in the Middle".

Checklist viết AGENTS.md chuẩn cho repo

  1. Độ dài dưới 150 dòng (tốt nhất là 50–100 dòng).
  2. Có lệnh build và test cụ thể, chạy được ngay không cần đoán tham số.
  3. Có ít nhất 2–3 quy ước khác thường (non-standard conventions) của dự án.
  4. Nêu rõ các thư mục hoặc file cấm tự ý chỉnh sửa.
  5. Không chứa bất kỳ nội dung nào thay đổi theo thời gian thực (giữ cache tĩnh).
