MCP

"JDBC cho context của agent": harness nói một giao thức, mỗi hệ thống ngoài cung cấp một server. Server là process riêng; người đọc API là model.

Hai tầng: data (JSON-RPC 2.0) và transport (stdio / Streamable HTTP). Nguồn: Architecture overview.

Sampling, Roots, Logging: deprecated ở 2026-07-28. Tool annotations (readOnlyHint, destructiveHint…) chỉ là hint, client phải coi là không tin cậy nếu server không tin cậy.

Spec 2026-07-28: stateless

  • Không còn initialize / notifications/initialized, không còn Mcp-Session-Id, không còn GET SSE stream.
  • Mỗi request mang _meta: io.modelcontextprotocol/protocolVersion + io.modelcontextprotocol/clientCapabilities.
  • server/discover: server bắt buộc có, client gọi nếu muốn. Client hiện đại thử discover, không được thì lùi về initialize (server cũ).
  • Tool cần trạng thái: truyền handle tường minh trong tham số.

Claude Code 2.1.292 (đo 2026-10-07): server/discover → subscriptions/listen → prompts|resources|tools/list → tools/call. Nguồn: changelog.

  • Tên tool: mcp__<server>__<tool> (dùng trong permission rule, hook matcher).
  • Tool search mặc định bật: lúc đầu chỉ nạp tên tool; model gọi ToolSearch để lấy schema.
  • Output: cảnh báo > 10k token, cắt ở 25k (MAX_MCP_OUTPUT_TOKENS).
  • Chọn server như chọn dependency: nó chạy với quyền của anh, output vào thẳng context.

Server tối thiểu (Python SDK 2.x)

# /// script
# requires-python = ">=3.10"
# dependencies = ["mcp>=2,<3"]
# ///
from mcp.server.mcpserver import MCPServer
from mcp.server.mcpserver.exceptions import ToolError

mcp = MCPServer("demo")

@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b

if __name__ == "__main__":
    mcp.run()   # stdio

Chạy: uv run server.py. Tutorial dùng FastMCP là bản 1.x (đã đổi tên ở 2.0, 2026-07-28). Java: Java SDK (io.modelcontextprotocol.sdk:mcp), Spring AI starter với @McpTool.
